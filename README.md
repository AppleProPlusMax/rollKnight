# rollKnight

A roguelite slot-machine auto-battler defense game built with HTML5 Canvas, ES Modules, and Web Audio API.

## Features
- **3x3 Fate Reels & Nudges**: Match 8 paylines (rows, columns, diagonals) to summon units or earn gold, with Crown wildcards & Jackpots. Use limited per-wave Nudges to shift reels into winning lines.
- **Unit Absorption & Branching Class Evolution**: Sacrifice extra units to level up core fighters and evolve 3★ units into specialized classes (Paladin, Berserker, Sniper, Windrunner, Archmage, Pyromancer, Vanguard, Dragon Knight, Necro Lord, Death Knight).
- **Core Relics**: Draft run-altering Cores after milestone waves.
- **20 Waves & Judgment Bosses**: Defend your castle across 20 waves including elite boss encounters.
- **Zero External Dependencies**: Pure Node.js static server + browser Canvas & procedural Web Audio SFX, with `中文 / EN` language toggle.

## Quick Start

```bash
npm start
```

Then open `http://127.0.0.1:4173` in your browser.

## Run Tests

npm test
